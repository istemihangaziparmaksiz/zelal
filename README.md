## 🌐 GitHub Pages ile İnternete Yükleme (2 Dakikada Canlı Link Al)

Sevgiline gönderebileceğin özel bir link (`https://kullaniciadi.github.io/date`) almak için:

1. **GitHub'a Giriş Yap**: [github.com](https://github.com) adresine git ve hesabına gir.
2. **Yeni Repository Aç**: 
   - Sağ üstteki `+` ikonuna basıp **"New repository"** seç.
   - Repository adına örneğin `date` veya `zelal` yaz.
   - **Public** (Herkese açık) olduğundan emin ol ve **"Create repository"** butonuna bas.
3. **Dosyaları Yükle**:
   - Açılan sayfada **"uploading an existing file"** linkine tıkla.
   - Bu klasördeki 3 dosyayı (`index.html`, `style.css`, `script.js`) sürükleyip bırak.
   - Aşağıdaki yeşil **"Commit changes"** butonuna bas.
4. **GitHub Pages'i Aç**:
   - Repository içinde üst menüden **Settings** (Ayarlar) sekmesine tıkla.
   - Sol menüden **Pages** seçeneğine tıkla.
   - **Branch** kısmından `None` yerine `main` (veya `master`) seç ve **Save** (Kaydet) de.
5. **Linkin Hazır! 🎉**:
   - 1-2 dakika içinde sayfanın üstünde `Your site is live at https://...` şeklinde linkin belirecektir.
   - Bu linki sevgiline gönderip tepkisini izleyebilirsin! ❤️
